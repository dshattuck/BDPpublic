
# BrainSuite Diffusion Pipeline (BDP)

BDP enables fusion of diffusion and structural MRI information for advanced
image and connectivity analysis. It provides various methods for distortion 
correction, co-registration, diffusion modeling (DTI and ODF) and basic ROI-wise
statistics. BDP is a flexible and diverse tool that supports a wide variety of 
diffusion datasets. For more information and detailed documentation, please 
see BDP website: http://brainsuite.org/processing/diffusion/

Created by Chitresh Bhushan, Divya Varadarajan, Justin P. Haldar,
           Anand A. Joshi,  David W. Shattuck, and Richard M. Leahy

# Downloading BDP

We have recently migrated the building and distribution of the BrainSuite Diffusion Pipeline
to GitHub. The latest release, v26a, is available on our [Releases page](https://github.com/dshattuck/BDPpublic/releases/tag/26a).

In addition to the latest builds, we have migrated our past eight open-source releases of BDP to GitHub. This includes reconstructing this repository's historical commits from these releases, as well as archiving the release packages.

# Running BDP
For detailed usage instructions on how to use BDP, please visit the [BDP pages on the BrainSuite website](https://brainsuite.org/processing/diffusion/). These pages also include details on how to build BDP.

> [!IMPORTANT]
> Please note that BDP is built using MATLAB and the MATLAB Compiler. This means you must have the correspoding MATLAB Runtime installed on your computer to run BDP. You must use the same version of the MATLAB runtime that was used to build the code. **You do not need a paid MATLAB license to run BDP!** Mathworks provides [free MATLAB Runtime libraries on their website](https://www.mathworks.com/products/compiler/matlab-runtime.html).
